# Wikinews, Global Storybooks and Tatoeba texts (CC BY)

- `news-*.txt`: articles from zh.wikinews.org by Wikinews contributors, Creative Commons Attribution 4.0 International
  (https://creativecommons.org/licenses/by/4.0/). Article and revision id per file in `../INDEX.md`. Sources sections cut; a few
  sentences dropped (see `../INDEX.md`).
- `global-storybooks-zh.txt`: 54 Mandarin stories from Global Storybooks (https://github.com/global-asp/global-asp, translations of
  African Storybook Initiative stories), Creative Commons Attribution 3.0 or 4.0 per story. Author, translator and illustrator of each
  story are in `global-storybooks-zh.credits.tsv`. Translators include dohliam, Vicky Liu, Xingxing (Winny) Wang and Xiaoya Ye.
- `tatoeba-juzi-jianti.txt`, `tatoeba-juzi-fanti.txt`: sentences from Tatoeba (https://tatoeba.org) by Tatoeba contributors, Creative
  Commons Attribution 2.0 France (https://creativecommons.org/licenses/by/2.0/fr/). Each sentence's id is in the matching `.ids.tsv`, in
  the same order as the lines after the title (https://tatoeba.org/sentences/show/<id>).

Test data only; not part of the app.
